# Gesture Controlled Virtual Mouse

A fun little thing I made, It uses real time camera feed to watch gestures to mimic a mouse. It uses Gesture recognition from media pipe and is mapped to keys by PyAutoGUI. Open to suggestions! 

## Libraries used: 
- MediaPipe
- Numpy
- OpenCV
- PyAutoGUI

## Features
- Cursor Movement: Relative cursor positioning using index finger tracking
- Left Click: Victory gesture (✌️).
- Right Click: Open Palm gesture (✋).
- Scrolling: Closed Fist gesture (✊) — move hand up/down to scroll vertically.
- q to leave application

## Prerequisites
- Python 3.9+
- Webcam
